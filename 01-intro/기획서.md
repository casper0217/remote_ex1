# 기획서: 개미와 베짱이의 숲속 이야기

## 누가 쓰나
수업에서 처음 만난 친구들

## 만들 것
가상 인물 ‘개미’가 친구 ‘베짱이’와 숲속에서 주고받는 장난을 그림책처럼 보여 주는 한 페이지 자기소개 웹페이지를 만든다.

## 가상 인물과 소개 내용
- **별명:** 개미
- **한 줄 소개:** 운동하고 노래 듣고 쉬는 걸 좋아하며, 베짱이를 깨우는 장난도 즐기는 교육생.
- **좋아하는 것:** 운동, 노래 듣기, 쉬기
- **베짱이와의 장난:** 개미가 낮잠 자는 베짱이를 깨우고, 베짱이는 느긋한 말로 받아친다. 서로 놀려도 마지막에는 함께 쉬고 간식을 나눈다.
- 실명, 연락처, 실제 사진은 넣지 않는다.

## 기능
- ‘개미 출동!’ 버튼을 누르면 개미 캐릭터가 움직이고 숲속 대사가 바뀐다.
- ‘숲 색깔 바꾸기’ 버튼을 누르면 페이지 배경색이 순서대로 바뀐다.
- **커서 조작:** 마우스나 손가락으로 무대 안을 움직이면 개미가 포인터를 따라간다. 개미가 베짱이 가까이 가면 만화처럼 살짝 툭 치고, 베짱이가 빙글 날아갔다가 제자리로 돌아온다. 베짱이를 직접 누르면 놀라며 새 대사가 나온다.
- 커서 조작은 별도 권한이나 인터넷 없이 사용할 수 있다. 버튼 조작도 함께 제공한다.

## 디자인 방향
- **전체 분위기:** 그림책 표지처럼 밝고 장난스러운 숲속 모험
- **구성:** 큰 제목 아래 잎사귀 무대를 펼치고, 직접 그린 개미와 AI 안경을 쓰고 기타를 든 베짱이를 주인공으로 보여 준다.
- **색상:** 하늘색, 잎사귀 초록색, 크림색을 중심으로 쓰고 따뜻한 주황색으로 강조한다.
- **장식:** 구름, 잎맥, 꽃, 딸기, 반짝임, 말풍선을 사용한다.
- **읽기 쉬움:** 문구는 짧고 글자와 배경색을 분명하게 구분한다.
- **작은 화면:** 휴대전화에서는 소개 상자와 버튼이 세로로 배치된다. 무대는 손가락으로 조작하기 쉽게 유지한다.

## 화면 구성
1. 그림책 표지처럼 큰 제목과 개미의 인사
2. 잎사귀 무대 위의 개미와 AI 안경 쓴 베짱이 그림, 대화 말풍선
3. 좋아하는 것 세 가지
4. 숲속 대사와 캐릭터 반응
5. 개미 출동과 숲 색 변경 버튼
6. 마우스·손가락으로 개미와 베짱이를 움직이는 무대
7. 친구들에게 전하는 짧은 인사

## 구현 조건
- 결과물은 `01-intro/index.html` 하나로 만든다.
- HTML, CSS, JavaScript는 모두 한 파일에 작성한다.
- 외부 라이브러리, 서버, 데이터베이스, 외부 그림 파일은 쓰지 않는다.
- 화면 문구는 한국어로 작성한다.
- 실제 개인정보나 허락받지 않은 사진은 사용하지 않는다.
