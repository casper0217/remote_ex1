# 기획서: 별빛 벽돌깨기 게임

## 1. 프로그램 개요
- **프로그램 이름:** 별빛 벽돌깨기
- **저장 폴더:** `02-bricks`
- **만들 파일:** `brick_game.html`, `brick_game.css`, `brick_game.js`
- **목표:** 왼쪽의 통통한 뱃살 범퍼로 혜성 공을 튕겨 오른쪽 수정 벽돌을 깨고, 단계별 난이도와 스킬, 콤보를 즐기는 가로형 게임을 만든다.

## 2. 기본 규칙
- 공 한 개로 시작한다. 처음 공은 왼쪽 뱃살 옆에서 대기하고, 스페이스키를 누르면 오른쪽 벽돌을 향해 발사한다.
- 공은 오른쪽 벽돌과 게임판의 위·아래·오른쪽 경계에 부딪혀 튕긴다. 오른쪽에서 왼쪽으로 돌아오는 공은 왼쪽의 둥근 뱃살 범퍼에 맞으면 다시 오른쪽으로 튕긴다.
- 왼쪽 경계는 벽이 아니다. 뱃살 범퍼를 맞히지 못하고 게임판 왼쪽 밖으로 나가면 목숨이 하나 줄어든다.
- 목숨은 3개다. 모두 잃으면 게임 오버이며, 스페이스키로 새 게임을 시작한다.
- 휴대전화는 화면의 공 발사 버튼이나 게임판 터치로 시작할 수 있다.
- 벽돌을 깨면 기본 10점을 얻는다. 2.2초 안에 연속으로 벽돌을 깨면 콤보가 쌓이고, 3콤보마다 점수 배율이 1씩 올라가며 최대 8배까지 적용한다.
- 현재 벽돌을 모두 깨면 다음 단계가 시작된다.

## 3. 단계별 난이도
- 벽돌은 오른쪽에 7개 층으로 놓고, 각 층에 세로 8개씩 배치한다. 총 56개다.
- 단계가 오를 때마다 공 속도가 12% 증가하며 최대 1,000px/초로 제한한다.
- 2단계부터 벽돌이 두 번 맞아야 깨진다. 이후 두 단계마다 벽돌의 기본 내구도가 1회씩 더 증가하며 최대 4회까지 맞아야 깨진다.
- 다음 단계에서는 벽돌이 새로 배치되고 더 단단해진다.

## 4. 화면과 크기
- 웹페이지 바깥 배경은 흰색이다. 게임판 안은 별과 은하수 빛이 있는 어두운 남보라색이며, 벽돌은 빛나는 보석 색으로 표시한다.
- 공은 동그란 원 대신 꼬리가 빛나는 마름모형 혜성 결정으로 그린다. 충돌 판정에는 공의 간단한 크기 범위를 사용한다.
- 게임판 기준 크기는 1,200×900이다. 브라우저 창 크기와 화면 배율에 맞춰 비율을 유지하며 축소하고, 창 크기나 화면 방향이 바뀌면 다시 맞춘다.
- 벽돌 기본 크기는 100×100px 정사각형이다. 오른쪽에 가로 7개 층, 세로 8개 줄로 놓고 작은 화면에서는 비율을 유지해 줄인다.
- 첫 벽돌 층은 게임판 왼쪽에서 350px 위치에 놓아 공이 오갈 통로를 확보한다.
- 왼쪽 뱃살 범퍼는 살구색 세로 타원형이며 기본 높이 150px, 폭 72px다. 넓은 뱃살 스킬을 받으면 높이가 230px로 늘어난다.

## 5. 조작 방법
- **스페이스키:** 공 발사, 게임 오버 뒤 새 게임 시작
- **위쪽·아래쪽 방향키:** 왼쪽 뱃살 범퍼를 위아래로 이동
- **마우스 포인터:** 게임판에서 위아래로 움직여 뱃살 위치 조절
- **터치 화면:** 손가락을 위아래로 움직여 뱃살 위치 조절. 시작할 때 게임판을 한 번 누르면 공을 발사한다.
- 휴대전화용 공 발사 버튼도 제공한다.

## 6. 스킬과 추가 재미 요소
- 벽돌을 깨면 14% 확률로 스킬 아이템 하나가 왼쪽으로 이동한다. 뱃살 범퍼로 받으면 즉시 발동하며 10초 동안 유지된다. 놓친 아이템은 화면 왼쪽 밖으로 사라진다.
- 한 번에 한 가지 스킬만 켜지고, 새 스킬을 받으면 이전 효과를 바꾼다.
  1. **관통:** 공이 벽돌을 맞혀도 튕기지 않고 통과한다.
  2. **큰 공:** 혜성 결정의 크기가 커진다.
  3. **넓은 뱃살:** 뱃살 범퍼의 세로 높이가 150px에서 230px로 늘어난다.
  4. **느린 시간:** 공의 움직임이 평소보다 느려진다.
- 활성 스킬 이름과 남은 시간이 화면에 표시된다.
- 연속으로 벽돌을 깨면 콤보 안내와 추가 점수를 받는다.
- 여러 번 맞아야 하는 벽돌은 남은 내구도 횟수를 표시한다.

## 7. 파일과 구현 조건
- `02-bricks/brick_game.html`: 화면 구성
- `02-bricks/brick_game.css`: 흰 페이지, 신비로운 게임판과 반응형 배치
- `02-bricks/brick_game.js`: 캔버스 그리기, 공·벽돌·뱃살 충돌, 조작, 점수, 단계, 스킬 처리
- 외부 라이브러리, 서버, 데이터베이스, 외부 그림 파일은 사용하지 않는다.
- HTML 파일을 더블클릭해 브라우저에서 바로 실행할 수 있게 한다.
